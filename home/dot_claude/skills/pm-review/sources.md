# Sources

- **The AI-Native SDLC Playbook** (Anthropic Applied AI, 2026-08-21): https://claude.com/blog/the-ai-native-sdlc-playbook
  Six stages (Plan, Design, Build, Test, Deploy, Maintain), linked by committed files. Humans sit at the gates. Skills only advise; hooks and settings enforce. Quote: "the agent may act up to the production gate and cannot pass it."
- **Best practices for Claude Code:** https://code.claude.com/docs/en/best-practices
  Tell Claude what it can't see, give it a check to run, enforce the rules that can't have exceptions, keep CLAUDE.md short.
- **Effective harnesses for long-running agents:** https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents
  Progress file, structured feature list, one feature at a time, test end to end, commit each step, leave a clean state.
- **Our framework for developing safe and trustworthy agents:** https://www.anthropic.com/news/our-framework-for-developing-safe-and-trustworthy-agents
  Human control, transparency, alignment with values, privacy, security.
- **The AI Fluency Framework (4D):** https://www-cdn.anthropic.com/334975cdec18f744b4fa511dc8518bd8d119d29d.pdf
  Delegation, Description, Discernment, Diligence (Anthropic with Rick Dakan and Joseph Feller).
